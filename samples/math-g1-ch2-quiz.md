## 二、多選題（每題 5 分，共 6 題）

**計分方式**：答對 5 分；錯 1 個得 3 分；錯 2 個得 1 分；錯 3 個以上 0 分。

**13.** 關於二次函數 $y = ax^2 + bx + c$（$a \ne 0$），下列哪些正確？（可複選）  
(1) 對稱軸為 $x = -\dfrac{b}{2a}$  
(2) 若 $a > 0$，函數有最小值  
(3) 判別式 $D = b^2 - 4ac > 0$ 時，圖形與 $x$ 軸交於兩點  
(4) 頂點的 $y$ 坐標為 $\dfrac{4ac - b^2}{4a}$  
(5) 若 $c = 0$，圖形必過原點

**14.** 關於綜合除法與餘式定理，下列哪些正確？（可複選）  
(1) $f(x)$ 除以 $x - a$ 的餘式為 $f(a)$  
(2) 除以 $2x - 1$ 時，應以 $x = \dfrac{1}{2}$ 代入求餘式  
(3) 缺項時不必補 0  
(4) 除以 $2x - 1$ 時，商式要再除以 2  
(5) 若 $f(a) = 0$，則 $x - a$ 是 $f(x)$ 的因式

**15.** 關於複數，下列哪些正確？（可複選）  
(1) $i^4 = 1$  
(2) $(a+bi) + (c+di) = (a+c) + (b+d)i$  
(3) $\sqrt{-4} = 2i$  
(4) 實係數方程式若有虛根 $p+qi$，則 $p-qi$ 也是根  
(5) $(1-i)(1+i) = 2$

**16.** 關於多項式方程式，下列哪些正確？（可複選）  
(1) 三次實係數方程式至少有一實根  
(2) $n$ 次方程式在複數中恰有 $n$ 個根（重根依重數計）  
(3) 一次因式檢驗法只適用整係數多項式  
(4) 若 $f(1) \cdot f(2) < 0$，則 $(1,2)$ 內至少有一實根  
(5) $x^2 + 1 = 0$ 在複數中有兩根

**17.** 解多項式不等式時，下列哪些敘述正確？（可複選）  
(1) 偶數重根處，符號不變  
(2) 奇數重根處，符號改變  
(3) 解 $f(x) \ge 0$ 時，重根處若值為 0 應納入解  
(4) 領導係數為負時，可先乘以 $-1$ 再判斷  
(5) 二次不等式「小於取中間」在 $a > 0$ 時成立

**18.** 下列哪些可能是 $f(x) = x^3 - 3x + 2$ 的因式？（可複選）  
(1) $x - 1$　(2) $x + 1$　(3) $x - 2$　(4) $x + 2$　(5) $2x - 1$

### 選填

**19.** $x^3$ 項：$-3x^3$；$x^2$：$5x^2 - 6x^2 = -x^2$？ 展開：$x^3 - 2x^2 - 3x^3 + 6x^2 + 5x - 10 = -2x^3 + 4x^2 + 5x - 10$，$x^2$ 係數 **4**。

重算 **19**：$(x^2-3x+5)(x-2) = x^3 - 2x^2 - 3x^2 + 6x + 5x - 10 = x^3 - 5x^2 + 11x - 10$，$x^2$ 係數 **$-5$**。

**20.** $f(-1) = 1 - 2 + 3 = 2$。  
**21.** $(x-4)(x+2)=0$ ⇒ $-2, 4$。  
**22.** 數線符號：解 $x \le -2$ 或 $-1 \le x \le 1$ 或 $x \ge 3$？ 根 $-2,1,3$：最右+，$x>3$ +，$1<x<3$ -，$-1<x<1$ +，$-2<x<-1$ -，$x<-2$ +。$\le 0$：$-2 \le x \le -1$，$1 \le x \le 3$。最大整數 **3**。  
**23.** $2a+b=4$，$-a+b=-2$ ⇒ $a=2$，$b=0$。

### 非選

**25.** 綜合除法：商 $2x^2 + 3x - 1$，餘 **0**（驗算 $f(1)=2+1-4+3=2 \ne 0$）→ 餘 **2**。

重算 $f(1)=2+1-4+3=2$，餘 **2**；商：  
```
 1 │  2   1  -4   3
   │      2   3  -1
   └──────────────
      2   3  -1 │ 2
```

**26.** 試 $x=-1$：$-1-4-1+6=0$，因式 $(x+1)$，得 $(x+1)(x^2-5x+6)=(x+1)(x-2)(x-3)$，根 $-1,2,3$。

**27.** 虛根 $1-i$，因式 $(x-3)(x-(1+i))(x-(1-i)) = (x-3)(x^2-2x+2) = x^3 - 5x^2 + 8x - 6$。

**28.** 移項：$\dfrac{(x+1)^2(x-2)}{x-1} \ge 0$，$x \ne 1$。根 $-1$（偶）、$2$、$1$（無）。解：$x = -1$ 或 $1 < x \le 2$ 或 $x > 2$ 且分子≥0… 詳細數線：$x<-1$ 區 +（偶根不變從右+），$-1<x<1$ +，$1<x<2$ −，$x>2$ +。≥0：$x=-1$，$x>2$ 或 $1<x\le 2$ 中負區… 重新：右端+，過 $x=2$ 變−，過 $x=1$ 無，過 $-1$ 不變。$x>2$：分子 $(+)(+)>0$；$1<x<2$：$(+)(−)<0$；$-1<x<1$：$(+)(−)<0$；$x<-1$：$(+)(−)<0$；$x=-1$：0。解：**$x = -1$ 或 $x > 2$**。

**29.** 設 $f(x)=ax^2+bx+c$：$a-b+c=4$，$a+b+c=0$，$4a+2b+c=3$ ⇒ $a=2,b=-1,c=-1$，$f(x)=2x^2-x-1$。
