## 1-1 Codex 是什麼

### 一、從「聊天」到「代理」

| 比較 | 一般聊天（例如 ChatGPT 的 Chat） | Codex（AI 程式代理） |
|------|------|------|
| 你得到的東西 | 一段文字回答或程式碼 | **直接改好的檔案**、執行結果、測試結果 |
| 能不能碰你的檔案 | 不能，要你自己複製貼上 | **可以讀寫你指定資料夾裡的檔案** |
| 能不能執行指令 | 不能 | **可以在沙箱中執行指令**（例如跑測試、執行 Python） |
| 工作方式 | 一問一答 | 自己規劃步驟、反覆嘗試、直到完成 |

- **Codex** 是 OpenAI 推出的 **AI 程式代理（coding agent）**：你用自然語言描述目標，它會閱讀程式碼、修改檔案、執行指令、檢查結果，最後回報做了什麼。
- 💡 「Codex」這個名稱最早是 OpenAI 在 2021 年推出的程式模型；現在說的 Codex，指的是這個會實際動手做事的**代理產品**。

### 二、代理的工作循環

```
你描述目標
   ↓
① 理解：讀取資料夾中的檔案、說明文件（例如 AGENTS.md）
② 計畫：拆解步驟
③ 動手：修改檔案、執行指令
④ 驗證：跑測試、看輸出，有錯就回到 ③ 修正
⑤ 回報：說明改了哪些檔案、結果如何
```

> **例 1**　你在 ChatGPT 的 Chat 中請它「寫一個檢查測驗卷答案分布的 Python 程式」，和在 Codex 中說同一句話，結果有什麼不同？
>
> Chat 會**給你一段程式碼**，你要自己存檔、執行、除錯。
> Codex 會**直接在資料夾中建立程式檔、實際執行**它檢查你的測驗卷，有錯就自己修正，最後告訴你檢查結果。
> **Codex 的重點在「把事做完」，不只是「給建議」。**

## 1-2 使用介面

### 一、主要介面一覽

| 介面 | 在哪裡用 | 適合 |
|------|------|------|
| **ChatGPT 桌面 App 中的 Codex** | macOS、Windows、Linux 的 ChatGPT 桌面 App，從下拉選單選 **Codex** | 不想碰終端機、想要圖形介面，同時處理多個專案 |
| **Codex CLI** | 終端機（PowerShell、macOS／Linux 終端機） | 習慣用指令、需要腳本與自動化 |
| **IDE 擴充** | VS Code、Cursor、Windsurf（擴充套件）；JetBrains、Xcode 有各自的整合 | 寫程式時直接帶入已開啟的檔案與選取的程式碼 |
| **Codex Cloud** | ChatGPT 網頁、行動裝置、桌面 App 中選 **Work in → Cloud** | 長時間任務、電腦關機也能繼續做 |
| **GitHub 程式碼審查** | 在 Pull Request 留言 `@codex review` | 團隊協作，請 Codex 審查程式碼 |
| **自動化** | `codex exec`、GitHub Action、Codex SDK | 排程、CI（持續整合）流程 |

- 💡 CLI 和 IDE 擴充使用**同一個代理**、共用同一份設定檔，學會一個，另一個就很快上手。

### 二、ChatGPT 中的三種用途

| 用途 | 做什麼 |
|------|------|
| **Chat** | 快速問答、討論想法 |
| **Work** | 研究、分析資料，產出文件、簡報、試算表等成品 |
| **Codex** | 軟體開發：帶著程式碼脈絡與開發工具工作 |

### 三、怎麼選介面？

> **例 2**　下列三位老師各適合用哪一種介面？
> - 甲：完全沒用過終端機，想請 AI 幫忙整理一個資料夾裡的 Markdown 講義。
> - 乙：常用 VS Code 寫網頁，想請 AI 修改目前打開的這個檔案。
> - 丙：想要每天晚上自動檢查一次教材資料夾，產生報告。
>
> 甲：**ChatGPT 桌面 App 的 Codex**（圖形介面，開啟資料夾即可）。
> 乙：**IDE 擴充**（直接帶入目前開啟的檔案）。
> 丙：**Codex CLI 的 `codex exec`** 搭配排程（第 9 章）。

## 1-3 登入與方案

### 一、兩種登入方式

| 方式 | 計費 | 說明 |
|------|------|------|
| **用 ChatGPT 帳號登入**（Sign in with ChatGPT） | 使用訂閱方案內的用量 | 一般使用者最常用；**Codex Cloud 必須用這種方式** |
| **用 API 金鑰登入** | 依實際用量計費 | 適合自動化與 CI；部分功能可能無法使用 |

- 登入方式也決定資料處理政策：ChatGPT 登入依工作區（workspace）的設定；API 金鑰依 API 組織的設定。
- ⚠️ API 金鑰就像密碼，**不要貼到對話中、不要寫進程式碼或上傳到 GitHub**。

### 二、方案

- 依官方說明，Codex 包含在 ChatGPT 的 Free、Go、Plus、Pro、Business、Edu、Enterprise 等方案中；**各方案的用量上限與可用功能不同**，例如 Codex Cloud 依方案與工作區設定開放。
- 本課程**不寫價格與確切用量**，請以官方定價頁為準：<https://learn.chatgpt.com/docs/pricing>

## 1-4 能力與限制

### 一、擅長的工作

| 類型 | 教學工作中的例子 |
|------|------|
| 寫小工具、腳本 | 寫 Python 程式檢查 40 份測驗卷的答案是否平均分布 |
| 批次處理檔案 | 把資料夾中所有講義的標題格式統一 |
| 解釋程式 | 說明一份同事留下的試算表巨集在做什麼 |
| 除錯 | 找出網頁版學習單為什麼按鈕沒反應 |
| 審查 | 檢查剛寫好的程式有沒有明顯錯誤 |
| 建立網頁或小應用 | 做一個單字測驗網頁 |

### 二、限制與風險

| 限制 | 說明 | 因應 |
|------|------|------|
| **會出錯** | 可能誤解需求、寫出有 bug 的程式 | 檢查修改內容（diff）、實際測試 |
| **只知道你給的脈絡** | 不知道你沒說的規則 | 寫清楚需求，或寫進 AGENTS.md（第 5 章） |
| **受權限限制** | 預設只能改目前資料夾、網路關閉 | 依需要調整（第 3 章） |
| **用量有上限** | 方案內的用量會用完 | 任務切小、善用 `/compact` 等功能 |
| **對話長度有限** | 上下文視窗（context window）有限 | 長任務分段進行 |

> **例 3**　Codex 回報「已修正所有錯誤，測試全部通過」，你可以直接相信嗎？
>
> **不行直接相信。** 應該自己看一下修改了哪些檔案（`/diff`），並實際執行一次確認。Codex 是很能幹的助手，但**最後負責的是你**。

### 三、使用前的好習慣

- 用 **Git** 管理資料夾，在任務前後建立檢查點（commit），改壞了可以還原。
- 從小任務開始，熟悉後再交付較大的工作。

## ⚠️ 常見錯誤整理

| 錯誤觀念 | 正確觀念 |
|------|------|
| Codex 只是會寫程式碼的聊天機器人 | Codex 是代理，會實際改檔案、執行指令、驗證結果 |
| Codex 可以任意存取整台電腦 | 預設受沙箱限制，通常只能寫入目前資料夾，網路預設關閉 |
| 一定要會寫程式才能用 Codex | 可用自然語言描述目標；但理解成果仍需要一些基礎 |
| CLI 和 IDE 擴充是兩個不同的 AI | 使用同一個代理、共用設定 |
| Codex 說完成了就一定正確 | 需要檢查 diff 並實際測試 |
| API 金鑰可以貼給 Codex 讓它幫忙設定 | 金鑰不要貼進對話，用環境變數或官方登入流程 |
| Codex Cloud 可以用 API 金鑰登入 | Codex Cloud 需要用 ChatGPT 帳號登入 |
| 所有方案的功能和用量都一樣 | 各方案用量與可用功能不同，以官方頁面為準 |

## ✅ 練習題解答

<details>
<summary>點我展開解答</summary>

1. Codex 會實際讀寫檔案、執行指令並驗證結果；一般聊天機器人只給文字回答。
2. 理解 → 計畫 → 動手 → 驗證 → 回報。
3. 任寫四種：ChatGPT 桌面 App 的 Codex、Codex CLI、IDE 擴充、Codex Cloud、GitHub 程式碼審查、自動化（codex exec／SDK）。
4. ChatGPT 帳號：一般日常使用、使用訂閱用量；API 金鑰：自動化、CI，依用量計費。
5. Codex Cloud。
6. IDE 擴充；可以直接帶入目前開啟的檔案與選取的程式碼。
7. 改壞時可以還原，也方便比較 Codex 修改了什麼。
8. Work 用於研究、分析與產出文件簡報；Codex 用於軟體開發，帶有程式碼脈絡與開發工具。
9. 看修改內容（diff）、實際執行或測試。
10. 例：會出錯 → 檢查並測試；不知道沒說的規則 → 寫清楚或寫進 AGENTS.md；受權限限制 → 依需要調整；用量有限 → 任務切小。
11. 參考：寫腳本檢查測驗卷答案分布（CLI）；統一資料夾講義格式（桌面 App）；每晚自動產生教材檢查報告（codex exec 排程）。
12. 參考：Codex 預設在沙箱中執行，通常只能寫入目前資料夾、網路關閉，超出範圍會先詢問；搭配 Git 檢查點可以還原；只要檢查 diff 並測試，就能安全使用。
